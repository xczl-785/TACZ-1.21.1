# TaCZ 外置枪械检查工作台

根目录双击 `启动TaCZ枪械检查工作台.command`，或执行：

```sh
./启动TaCZ枪械检查工作台.command
```

浏览器打开终端显示的本地地址。工具编译独立 Java worker，读取生产侧 `AssembledWeapons`、`AssemblyEngine`、`ModelGeometry` 与 `AssemblyMaterials`；不启动 Minecraft，不修改枪械、配件、库存、世界或正式资源。

当前用途：切换实验室枪械、查看默认或临时装配、安装/拆卸候选配件、旋转缩放中性几何、查看每个零件的装配原点与附件原点、保存截图。网页不重新判断兼容性，所有编辑必须经过生产 `AssemblyEngine`。

## TaCZ 与自有枪械的坐标差异

自有枪械以独立零件和装配槽位为原生结构。TaCZ 原生枪首先是一套带骨骼的整枪模型，实验室再用 `native-profile.json`、骨骼显隐规则、原生附件映射和生成的 `preview.json` 投影为装配树。因此 TaCZ 同时存在原生骨骼枢轴、父零件槽位锚点、子零件 attachment origin 三层坐标；工作台只共享后两层的纯装配合同，并明确不在网页伪造原生骨骼枢轴。

若中性装配正确、游戏原生画面错误，应检查骨骼枢轴/原生附件变换；若中性装配已经错误，应检查生成的槽位锚点或 attachment origin。这个分界用于定位，不代表外置画面等同 Minecraft 光照、透明材质、光学镜内效果或动画状态机。
