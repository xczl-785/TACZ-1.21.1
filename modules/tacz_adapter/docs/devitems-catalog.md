# 开发物品目录与适配器职责

2026-09-13：所有者发现`/devitems`把TaCZ基础注册壳列为紫黑物品，枪型缺席、迁移弹药仍按旧命名空间分类。本次修复目录与领取，不变更物品ID、枪重或配件机制。

## 当前行为

服务端生成完整目录并发送给客户端；界面按目录来源分组，搜索名称、条目编号或原物品ID。客户端领取只提交条目key与数量，服务端重新查询当前目录、复制完整预设，再经过既有权限/存活/数量与[标准搜刮／拾取规则](../../tactical/docs/pickup-rules.md)校验：先尝试空装备槽，再放入随身容器。客户端不能任意提交物品组件；隐藏的空壳和退役/伪造条目不能通过旧请求领取。

`tacz`分类共189项：15枪、85配件、86具体弹药、靶子/靶车/雕像。枪以正确型号、默认射击模式及空枪状态发放，配件携带具体配件编号。枪械/配件基础壳和原生弹药壳不展示。两种旧开发测试弹已按所有者2026-09-13要求删除，见[退役记录](test-ammo-retirement.md)。

86弹药的兼容ID仍为`tarkov_content:ammo_*`，由TaCZ fork提供内容，故来源显示`tacz`。命名空间不再被误当工程归属。普通物品默认沿用命名空间来源，其他适配器可通过同一目录扩展点提供真实归属。

## 模块职责

- `tactical/development`：通用目录扩展事件、目录传输、界面与领取校验；不引用TaCZ类。
- `tacz_adapter/development`：读取已接入枪和加载的配件索引，构造完整物品预设，指定迁移弹药来源；不进入正式Jar。
- `tacz_adapter/main`：仍存在，模组ID为`tactical_tacz_adapter`。负责胸挂/口袋供弹与退弹、弹药查看、命中交给combat，以及持枪/瞄准与装备资格连接；后续加入[Z改装库存桥](refit-inventory.md)。
- TaCZ fork：枪械引擎、模型/动画/效果、86弹药注册与资源。本目录修复批次未改变fork制品；后续Z扩展已更新运行锁，当前以[self-built-runtime](self-built-runtime.md)为准。

实测还发现非Glock枪没有公开库存身份，导致背包拒收。本次为最终保留枪补基础`firearm`身份，Glock继续是`pistol`；不把其他枪变成副武器，也不改变容器准入规则。领取仍受空间和准入约束；回归使用有空间的6Sh118背包，不绕过库存事务。

## 验证边界

服务端对189项逐项实际领取、核对型号/组件、保存读回；测试目录网络编码/解码与消息大小；拒绝基础壳、已删除枪及伪造key。客户端使用真实服务端导出目录与TaCZ入服同步数据，检查189项分组、M700选择、86弹药归属、搜索和分页，并渲染枪械目录。两部分是隔离自动验证，不冒充所有者实机接受或多人验收。

重启日常开发客户端后运行`/devitems`，切到`tacz`，搜索`M700`或`gun/m700`领取；弹药也在`tacz`来源下，仍可用旧ID搜索。日常世界未清空或改写。

验证通过：完整build、服务端/客户端smoke；[机器证据](devitems-verification.json)，[枪械目录截图](evidence/devitems-guns.png)。初次客户端夹具未模拟入服同步，现已使用服务器导出的TaCZ缓存执行正常缓存加载和客户端索引重建，未用虚构名称掩盖空壳。

## 历史定位：裸装领取失败（后续共用拾取已解决）

所有者截图：Glock 17领取1个，返回“无法放入：请检查战术库存空间与容器准入规则”。该消息表明服务端通过权限、存活、目录与数量检查，但`TacticalContent.tryGrant`返回false；不是型号查询失败。

核对日常客户端`runs/tactical-client/logs/latest.log`及同目录`新的世界/playerdata/380df991-f603-344c-a090-369bad2a924a.dat`（14:07退出保存）：角色固定装备槽全空、口袋为空的4×1、私人仓库为空的10×40。枪配置占2×1；`InventoryCapacityRules.accepts`限定口袋只能接收1×1。`QuickMovePolicy`只选口袋与已装备容器，枪槽、私人仓库和外部容器不作为领取目的地。因此按该已保存状态，唯一目的地口袋拒绝Glock。存档是退出快照，不是点击时的实时捕获；日志未输出具体拒绝原因，但快照和代码足以解释并重现该条件。

现有189项回归每次装备空6Sh118背包，证明有合适容量时可以领取，不代表裸装角色也能领取。该次仅定位，未修改规则。随后所有者明确授权统一搜刮／拾取入口：devitems现已与地面共用先装备后容器规则，空副武器槽可直接接收Glock；仍无合适槽位或容量时拒绝。当前语义与验证见[标准拾取规则](../../tactical/docs/pickup-rules.md)，下游不得把此规则扩大为所有入库的默认行为。
