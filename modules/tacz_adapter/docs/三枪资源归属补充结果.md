# 三枪资源归属补充结果

> 旧三枪生产链资料（`deprecated-asset`）：ADAR、Radian、单独导入 M4 的源、配置和部分脚本已退役。正文仅作来源/设计追溯，不能执行其中旧制作命令或据其简单红点能力判断当前原生瞄具。现行制作入口为[十五枪作者源](../weapon-sources/README.md)和[全量瞄具](../../../docs/assembly-experiment/optics-batch/README.md)。


2026-09-15。**资源归属清理完成；游戏体验仍由用户实机验收。** 本轮不修改 Java、Gradle、TaCZ 锁定文件、vendor 制品或弹药逻辑，不启动 Minecraft。

## 资源现在由谁负责

| 内容 | 归属与处理 |
| --- | --- |
| ADAR 木材、金属、聚合物、橡胶 4 张纹理 | 归 `weapon-content/resources/assets/newmod_adar/textures/materials/`；作者材质库的 6 处引用改为 `newmod_adar`；`import.json.textureCopies` 按 SHA-256 验证、按原始字节复制，不缩放或重编码 |
| M4A1 的 4 张 `firearm_materials` 纹理 | 这是 adapter 内的共享材质 namespace，不是另一个 Mod。保留资源 ID，把旧 `src/main/resources/assets/firearm_materials/` 迁到 `weapon-content/resources/assets/firearm_materials/`。生成器原本已生成这一组，本轮补齐归属与比较范围 |
| 雷电的 6 张纹理 | 原本就在本枪 `newmod_radian` namespace，无需迁移 |
| UI 原纹理 | 全部保留在 UI 模块，继续供其真实消费者使用；生产来源快照也保留原路径与哈希记录 |
| TaCZ 声音、枪口效果、默认动作与原有弹药 ID | 真实引擎接入合同，原样保留；只读核对锁定包内相关资源，没有清理或改写弹药数据 |
| `minecraft:item/generated` | Minecraft 自带物品模型父级，保留 |
| `item_foundation:type/*`、`tactical_inventory:primary_weapon_*` | 物品分类与装备槽位合同，保留 |

`AssemblyGunClient` 实际使用 `WorkbenchScreen` 和 UI session 接口，所以 `weapon_assembly_ui` 的 Java 依赖仍有真实用途，不删除。材质资源独立与界面代码依赖是两件事。

原始纹理来源仍在 `weapon-sources/adar/provenance.json`；作者配置负责新的目标资源 ID。ADAR 图标直接从本次生成的纹理读取，运行与离线图标消费同一份内容。雷电/M4A1 作者 `display.json` 中会被生成器覆盖的旧 ADAR 占位资源字段已移除，最终字段仍由各自 `runtime.json` 派生，生成数据不变。

## 修正上次的验证范围

上一批的 **175 文件只覆盖三枪自身 namespace 和注册索引**，不包含留在旧目录、却被 M4A1 引用的 4 张 `firearm_materials` 纹理。历史结果仅对那个集合有效，不能称作完整三枪内容验证。

- 修复前的完整同包内容：175 + 4 = **179 文件**。
- 本轮新增 ADAR 自有同字节纹理 4 张，完整内容为 **183 文件**。
- 对比工具现在沿材质库引用包含共享 namespace；本次还核对了 183 文件集合等于整个内容目录文件集合，无遗漏文件。
- 14 张材质纹理全部在隔离输出内解析。检查器与预览工具不再向旧 `src/main/resources` 或其他模块寻找缺失材质。

## 使用

仍使用同一个入口，在工程根运行，输出选择一个空目录：

```sh
python3 source/mods/tacz_adapter/tools/weapon_pipeline.py all \
  --output /tmp/newmod-weapon-material-review/resources \
  --reports /tmp/newmod-weapon-material-review/reports \
  --compare source/mods/tacz_adapter/weapon-content/resources
```

除转换和资源验证外，入口现在自动输出 `references.json`，列出全部资源 ID 使用位置、归属、材质哈希和外部 TaCZ 文件证据。对比会包含被引用的共享材质。

独立检查生产资源：

```sh
python3 source/mods/tacz_adapter/tools/validate_weapon_resources.py
python3 source/mods/tacz_adapter/tools/audit_weapon_references.py --report /tmp/newmod-weapon-references.json
./source/gradlew -p source :tacz_adapter:processResources :tacz_adapter:jar :tacz_adapter:verifyAdarIconRenderer
```

若另一任务正在更新锁定 TaCZ 包而哈希暂不一致，应等待其完成再检查，不自行修正锁定文件。本轮只依赖该包的已存在资源，不复制引擎资源到枪械内容。

剩余：真实 UI Java 依赖、TaCZ 引擎合同、foundation 分类与 tactical 装备槽位依赖继续保留；游戏中的外观、瞄准、换弹和拆装体验等待用户确认。非可拆弹匣、跨枪共同物品和独立发布包仍不在本轮范围。
