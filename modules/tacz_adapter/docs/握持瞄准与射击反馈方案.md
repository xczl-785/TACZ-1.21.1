## 模块责任

- `weapon_models`：纯定位/瞄准数学、配件标注合同、有效实例选择。可测试，不引用 TaCZ。
- `weapon_assembly` / 物理装配组件：配件身份、兼容关系和数值事实；不依赖镜头和动画。
- `tacz_adapter`：将定位结果接到 TaCZ 骨骼、视点与射击事件；只处理 `AssemblyGunModel` / `AssemblyGunItem`。
- `weapon-authoring/<gun>`：作者数据和可重放生成入口；旧 ADAR 源转换保留，但第一人称生成改走同一入口。

## 坐标和装配合同

现有 schema 3 网格已经把来源完整矩阵烘焙进共同美术坐标，运行装配槽存平移。局部定位点必须与该网格同坐标，不可把原始矩阵再次应用。定位结果经过同一 meshScale 和轴转换进入 TaCZ。后续未烘焙模型必须先扩展模型/工作台/定位共用变换合同，禁止仅旋转瞄准点却不旋转网格。

每个配件可声明右手/左手接触点、光学观察点或机械准星/照门。光学观察点含位置、朝向、眼距、优先级和模式 ID；身份是装配路径加模式 ID，不能只用 definition ID。禁用祖先下的全部点失效。机械瞄准需配套且方向相容的前后点。缺少有效瞄具时使用明确的非精瞄备用姿势，不伪造瞄具或红点。

握持采用可配置手臂模板加接触点解算，当前皮肤手臂保留 TaCZ 渲染；不声称解决通用肘关节 IK。范围异常在校准报告中指出，不静默拉长枪模。

## 射击合同

摄像机后坐力仍由 TaCZ 施加，装配的最终后坐力比例仅进入一次。视觉后退/抬枪由同一装配比例驱动，机械动作不随其缩放。单发输入给有界、时间连续的恢复系统；自动射击增加冲量，不把未结束动画突然重置到起点。瞄准时抑制视觉偏离，保留实际后坐力，不用约束抵消玩家压枪需求。原生枪不受自有规则影响。

原实现遗漏 `constraint`，且只写死 iron_view 和手角度。修正不能只把照门推远；需要同时统一手、眼、光轴和射击位移。

## 验证和交付边界

不启动游戏。自动验证覆盖候选选择、父级失效、安装位移、光轴/眼距、有限数值、恢复连续性与帧率差异；编译 main/development、资源验证、模块边界和国际化。最后补充精确结果及校准入口。实机握持、眼距、射击手感仍由所有者验收，未通过前不启动大量接入。

## 当前作者入口

每把枪的 `weapon-authoring/<gun>/markers.json` 定义配件标注，`handling.json` 定义手臂模板、备用观察姿势和反馈参数。通用 `build_presentation.py` 同时处理旧 ADAR 与原稿组件来源；完整导入命令也自动调用它。

```sh
python3 source/mods/tacz_adapter/tools/build_presentation.py source/mods/tacz_adapter/weapon-authoring/radian
python3 source/mods/tacz_adapter/tools/calibrate_weapon.py source/mods/tacz_adapter/weapon-authoring/radian source/mods/tacz_adapter/docs/calibration/radian.html
```

把目录改为 `adar` 就是同一流程。报告：[雷电](calibration/radian.html)、[ADAR](calibration/adar.html)。报告不渲染真实皮肤、镜片或 Minecraft 摄像机，只检查装配位置；不能据此声称握持不穿模。

标注合同：

- `parts` 以原版 definition ID 为键；每件可有多个 `sights` 和左右手 `contacts`。同一配件多次安装按完整 slot path 区分，禁止以 definition ID 保存玩家选择。
- `position` 使用该配件已烘焙网格的局部美术单位；`rotation` 为度，顺序 Rz × Ry × Rx；局部 +Z 为向前，+Y 为向上。
- `kind=optic` 提供独立光轴；`rear`/`front` 需要一致 `group`，且前准星位于后照门前方、横向误差不超过 0.5 美术单位。前准星缺失或匹配不唯一时，不生成该机瞄模式。
- `eyeDistance` 从光轴位置向后退；不是相机 z 的绝对值。`zoom` 是世界放大倍率，`modelFov` 是手持模型视场角，二者分别接入。
- `priority` 大者优先，同级按装配路径/模式 ID 排序；当前选择仍有效时保留。新装配、父级禁用/拆除使当前模式失效时自动回退。
- `contacts.role=left/right`，相同角色按优先级选择。前握把可以用更高优先级覆盖护木接触点；对应部件缺失后回到仍有效的接触点，没有接触点则隐藏该手，不能悬空假装握住。
- 手臂模板的 `palm` 是标准皮肤手臂局部手掌接触面坐标（本次采用 z=-2 的表面，而不是体积中心）；求解使用 TaCZ 实际动画四元数与缩放。保留换弹手臂位移，但本轮不校准换弹动作。不同皮肤宽度、极端组合仍需实机检查。

`handling.recoil.referenceVertical/Horizontal` 固定记录校准预设的装配数值。当前装配数值 / 固定参考 × `pitchScale/yawScale` 得到输入比例，不能在每次换配件后重算参考。`pitchScale=0` 表示关闭本枪的摄像机垂直后坐力及关联视觉抬枪；水平仍由 yawScale 控制。世界摄像机由 TaCZ 唯一施加，原生姿势/倍率修正保留。`visualKick`/`visualPitch` 控制视觉后退/抬枪，`adsMotion` 控制瞄准时保留的比例；都不缩放枪机、弹匣等机械动作。

## 当前支持范围与未验证项

本轮落地：已烘焙网格的装配定位、定义内多观察点、实例稳定选择、按键切换、机瞄完整性、接触点求解、视点过渡、固定参考后坐力桥接、连续视觉恢复、第一人称约束、纯数学与真实预设的静态校验。

`Frame` 数学支持旋转链，当前 schema 3 的实际模型装配槽仍只有平移；真实旋转底座应由来源转换同时烘焙网格和标注。合成旋转测试不等于已接入可自由旋转的运行时导轨。后续引入未烘焙通用配件时，要让网格、工作台和定位共用完整变换，不能单改瞄准逻辑。

光学瞄具当前是透明开口内的简单发光点，尚非无限远准直/PIP 镜片。倍率参数已接通，但完整倍率镜遮罩、眼箱黑边、弹道归零不在本轮完成范围。精瞄模式缺失时使用备用姿势，不改变已获准的射击就绪规则。

使用原有 `启动开发客户端.command`；如需独立验收，新建开发世界，不清空日常世界。通过 `/devitems` 的 `adar` / `radian` 各领取一把完整预设（分别是 `newmod_adar:adar`、`newmod_radian:radian`）；在 `/devitems` 的 `tacz` 来源搜索 `ammo_54527a984bdc2d4e668b4567`，领取 60 发（ID：`tarkov_content:ammo_54527a984bdc2d4e668b4567`），放入口袋供弹。通过武器槽取到手上，再右键瞄准、R 换弹后射击；Z 打开组装界面。首次启动后，按 NeoForge 实际加载位置检查 `config/raid_gameplay-server.toml` 的 `developmentMode=true`，重启生效；这是验收环境前提，不能用玩家命令开启。所有操作仍受既有库存规则控制，本轮不改动它们。

1. 原地持枪、转身与瞄准：掌心落在握把/护木下方，照门不占据大半屏幕；视点无突然拉近。
2. 雷电默认 MBUS 瞄准；拆掉前准星或后照门后不继续精瞄；装回恢复。ADAR 拆掉全息后不绘制红点、不保留旧镜头。
3. 默认 `]` 切换有效瞄准方式（可在按键设置中重绑）；当前默认预设只有一个有效方式，单模式切换不产生跳动。多模式先由合成回归覆盖，后续小批瞄具接入再实机验收。
4. 单发与连射：有后坐力但画面不会反复从零瞬移；停止后回到稳定状态。切换 ADAR/雷电不继承另一把枪的视觉余震。
5. 调整 `handling.json` 的 pitchScale 并重新生成/重启，对比 0、0.5、1；垂直后坐力及视觉抬枪同步变化，水平和机械动作独立。
