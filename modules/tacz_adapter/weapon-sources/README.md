# 十五把正式枪的生产来源

每把正式枪使用独立的 `native_<枪名>/` 作者源目录，保存其可编辑组件、安装关系、来源审计和构建报告。目录名是离线制作定位符，不是游戏内分类，也不是枪械 ID。

运行时枪械配置通过 `authoringSource` 精确指向对应目录；游戏开发物品目录统一读取 `developmentCategory: tacz_fork_tarkov`。因此可以统一玩家看到的分类，同时继续保持逐枪来源、哈希和重建能力。

废弃的 ADAR、单独导入 M4A1 和 Radian 作者源已删除。其历史报告仍留在 `weapon-reports/` 和文档中，只用于追溯，不参与构建或打包。不要在原稿或历史报告上试改；正式枪参数只在对应 `native_<枪名>/` 来源中维护。
