## 开发中确实被测试发现的问题

1. 第一组组装测试先运行，在未实现操作上失败（2/2），实现后通过。
2. 属性计算测试先运行，在未实现计算上失败（新增2项），实现后通过。
3. JSON 场景先运行，在未实现读写上失败（新增2项）。补实现后普通 JVM 缺 Gson，已显式加入与当前 Minecraft 相同的 Gson 2.10.1 测试依赖；没有为运行 Jar 内嵌第二份 Gson。
4. 真实数据揭示 recoilModifier 单位不同：顶层 -3 与 properties 中 -0.03。生成器改为消费后者，按源同步代码转换 accuracyModifier，并增加 Glock 确定数值断言。不是把负数结果静默截成 0。

这份证据不代表 UI、模型、真实物品交换、实际射击或多人/重启恢复已验证；这些仍在 README 的后续结果段。本批没有运行日常客户端，也没有修改世界或 TaCZ fork。
