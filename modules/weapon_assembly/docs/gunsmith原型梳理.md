# Gunsmith 原型界面与交互参考

原型位置：`/Users/zhengpanpan/Downloads/gunsmith-source`。本页用于后续 NewMod 界面实现时读取原型行为；不改变[算法合同](算法合同.md)，也不代表界面已经实现。

**保留的核心体验：整屏观察枪械 → 点部位标签 → 悬停候选预览模型与属性差异 → 点击安装。** 配件选择是贴着部位移动的紧凑浮窗；关闭浮窗仍可继续转动、缩放枪械。

用户已确定：使用 NewMod 现有标准界面库及一致控件风格，不采用手绘风格。这里记录信息布局和操作语义，Web CSS、React、Three.js 及其控件不作为移植技术方案。标准库的具体落点由 NewMod 侧调查确定。

## 2. 实际流程与状态变化

初始为 6 件默认件全部装上，内部 `selected = handguard`，浮窗关闭、无预览、撤销栈为空。即使浮窗关闭，内部仍保留选中部位及其高亮。

| 输入 | 当前原型结果 | 不变或限制 |
| --- | --- | --- |
| 悬停／键盘聚焦部位标签 | 对应已装模型轻度高亮 | 不打开浮窗、不更改配置 |
| 点击标签 | 选择该槽、清除旧预览、打开浮窗 | 当前选择仅是 6 个固定槽之一 |
| 悬停／聚焦候选 | 在渲染副本中替换所选槽；同步预览属性和差值 | 正式 `build`、撤销栈不变 |
| 离开／失焦候选 | 清除预览，恢复当前已装模型与属性 | 不回滚已经点击安装的操作 |
| 点击候选 | 立即替换，旧配置入撤销栈，清除预览 | 没有额外应用／保存按钮；点击当前件不增加历史 |
| 点击拆除 | 可选槽变空，旧配置入撤销栈，模型消失 | 护木、枪托、握把被硬编码为不可拆；空槽按钮禁用 |
| 点击另一标签 | 切换选择，浮窗跟随新标签 | 不修改枪械 |
| 关闭按钮／Esc | 关闭浮窗、清除预览 | 保留安装结果、选中槽、历史 |
| 点击控件外空白 | 主指针左键按下到抬起位移不超过 6px 才关闭浮窗 | 拖动不会关闭；按钮等控件排除在外 |
| 撤销 | 恢复最后一个历史 build，并弹出历史、清除预览 | 不恢复旧选择／相机；无 redo；浮窗开关不变 |
| 恢复默认 | 当前非默认配置先入历史，再恢复 6 件初始件 | 可以再次撤销“恢复默认”；已是默认则按钮禁用 |
| 复位视角 | 恢复相机位置与观察目标 | 不改变装配和历史 |

属性预览以 **当前已安装配置** 为比较基准，不是默认配置。人机增大为好、后坐和重量减小为好；这是原型的视觉正负方向。默认示例结果为 3.14kg、人机 55、垂直后坐 68。

## 3. 三维显示与镜头

- 使用 Three.js 的方盒、圆柱、导轨几何程序化生成 M4 轮廓，18 个配件变体对应不同几何／材质；没有加载 OBJ、GLB、Blockbench 或 EFTForge 图片／数据。
- 固定机匣、枪管等主体始终存在；仅 6 个装配组随 build 增删。每次候选／选择／悬停变化会重建显示模型。
- **点击的是覆盖在 Canvas 上的 HTML 标签，不是射线拾取模型网格。** 标签有固定三维坐标，转动镜头时投影到屏幕；空槽标签仍然存在，可以重新安装。
- 所选部件轻度金色发光，候选预览增强发光；标签悬停可暂时改变模型高亮，但选中标签状态不变。
- OrbitControls 禁止平移，开启阻尼，旋转速度 0.65；相机距离限制 5–16，俯仰角限制 0.35 至 π−0.35。初始目标 `(-0.5, -0.16, 0)`，相机 `(-0.1, 2.2, 9.8)`；窄比例视口初始距离 12.8。这些是原型模型尺度下的参数，不应机械抄给新模型。
- 未做模型遮挡检测、标签避让、递归标签展开，也未把浮窗避让范围扩展到左下属性区。标签只检查投影深度是否大于 1。
- WebGL 初始化失败显示硬件加速错误提示；没有二维备用编辑入口。

## 4. 演示数据和正式算法的边界

原型 `Build = Record<string, string | null>`，配件 ID 是 `slot-index`，不是实例 UUID。数据只有固定 6 槽 × 3 候选；全局固定件基础属性为重量 1.85、人机 48、后坐 78，配件值直接相加。

| 原型假设 | NewMod 接入要求 |
| --- | --- |
| 同类槽的 3 件全兼容，直接覆盖字符串 | 从 AssemblyCatalog 和 AssemblyEngine 取得合法候选／计划；失败保留原树并显示原因 |
| 6 个平面槽就能描述整枪 | 使用完整槽路径与递归 AssemblyNode，区分同名槽、转接件和其子槽 |
| 必需件不能拆 | 正式合同允许缺必需件的合法结构，返回缺失路径和 `complete=false`；不应据原型禁用拆除 |
| 替换只丢弃旧字符串 | 正式计划有 detached 子树；旧部件与其子件必须完整保留，后续库存交换处理实际去向 |
| 无限量候选、无实例状态 | UI 测试夹具可以提供可选样本；不能被解释成正式玩家无限生成资产 |
| 属性简单加法 | 使用 WeaponStats 正式公式；UI 只格式化当前值和预览差值 |
| 撤销／恢复默认任意回退配置 | 可以作为隔离交互测试的工作副本操作；接真实库存后需重新规划和校验资产交换，不能直接回写历史快照 |
| 自动应用即本地 React 状态变更 | 不代表服务端提交、持久化成功或扣除返还完成；宿主决定提交语义 |

该原型未实现：递归组装、跨槽冲突、占用关系、库存扣返、保存／重载、多人同步、实际射击、搜索筛选、自动最优配装、模型爆炸视图、网格拾取。以上均不能从界面字样推定已存在。
