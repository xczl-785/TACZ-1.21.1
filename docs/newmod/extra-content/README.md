## 抛壳效果保留证据

对清理前哈希清单逐文件比对186个ammo索引/显示、弹药模型贴图与枪口效果相关资源：全部存在且字节未变。24份原ammo索引仍保留，枪上的ammo_id继续用于渲染映射；新增具体弹种的注册ID不会替换这个显示ID。
