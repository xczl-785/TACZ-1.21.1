## 变化与保留

- R07：移除 KillAmountOverlay 的累计数、计时、注册和配置。真实伤害、击杀事件、ServerMessageGunKill、普通命中/击杀标记及其音效保留。
- R07：移除原生枪械/附件/已退休方块的自定义 tooltip、物品生成入口、工厂注册、高级 ID 说明事件、hide_tooltip_part 命令及独占字段。退出只供旧说明使用的包信息展示解析和装配键文案桥；公共装配键与 provider 不依赖该桥。名称、图标、身份、物理属性、公共查看/装配和 Minecraft 全局 tooltip 保留，不补一套新说明。
- 原生附件的文本生成、旧改装图表方法和对应语言键已无消费者，随旧前端退出；JsonProperty 保留为实际属性值容器。32 个保留的 eval/initCache 方法体与基线相同，公共属性投影未修改。
- R09：移除弹丸点燃实体/方块、点燃粒子、点燃配置/属性/modifier/解析及同步字段。Lua 脚本中没有点燃调用；移除 RuntimeOnly 点燃属性后也不再有脚本覆盖的消费点。移除正式枪和内置源数据中的 ignite 字段；其他弹道字段语义保持。
- 仅移走 DebugCommand / GunMeleeDebug 到 development。正式近战逻辑发布只读 GunMeleeRangeEvent，开发包监听后按调试开关画粒子，并独立注册 /tacz debug。正式包不引用开发实现；开发包命令沿用管理员权限。
- DummyAmmo 被真实供弹、换弹、Lua、动画状态和 AmmoBridge 使用，未证明开发独占，因此机制与命令保留。附件锁仍由 AssemblyGunExchange 使用；创造栏、配置、reload 均保留。
- 清除无消费者的 GunPackProgressScreen、FlatColorButton、空 ListPackCommand、下载器注释及专属语言键；LoadingConfigEvent 的配置初始化保持。

## 爆炸和过热的归宿

保留 EntityKineticBullet → ExplodeUtil → ProjectileExplosion 及爆炸数据/modifier，供未来手榴弹实现参考。当前这是弹丸命中/超时爆炸路径，未发现独立手榴弹实现；未来手榴弹爆炸是待实现需求，不是已存在能力。本批不删除爆炸，也不修改 Minecraft 全局火焰。过热继续保留，未来自有/公共枪械必须有过热能力。

## 数据与来源核对

[source-audit.json](source-audit.json) 记录逐文件旧新 SHA-256、相同口径代码量、保留的计算方法与资源语义比较。只删退休说明/点燃字段，图片、声音、模型、动画、Lua 未变。

源枪数据字段退出后，原有作者 build-report/geometry-evidence 的输入指纹需要同步；仅对已通过字段级语义比较的源文件更新指纹，模型和几何结果未重生成/改变，现有 15 枪合同验证继续执行。逐项见 [author-fingerprint-refresh.json](author-fingerprint-refresh.json)，不放松生产验证器。

本批删去弹丸 spawn 数据的两个点燃布尔值，因此 TaCZ 网络版本改为 `1.0.5-slim4`，客户端/服务端应同版本；公共 NewMod 依赖 pins 不变。旧世界 NBT、游戏目录和外部包均不主动修改。
