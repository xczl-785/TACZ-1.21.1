# NewMod fork 改动记录

### 2026-09-24 受管 15 枪范围门禁

以 `assembled_weapons.json` 的 15 个正式枪 ID 为唯一允许清单。TaCZ 平台扩展新增 `allowsGun`，生成器、创造栏枪械列表和图标只呈现清单内枪；配方若引用范围外枪，生成结果为空。服务端与客户端的开火、瞄准、换弹门禁同时拒绝范围外 ID、伪装成受管 ID 的原生物品和无效组装枪。原生默认枪包与用户目录保留，供共享资源和历史物品读取；本次没有删除模型、动画、音效或本地世界。已有范围外物品仍可被 Minecraft 反序列化，但不能继续执行枪械动作。

范围：`GunPlatformExtension`、`GunItemBuilder`、`AbstractGunItem`、`ModCreativeTabs` 及 `tacz_adapter` 的平台扩展/射击门禁；新增 15 枪允许清单测试，开发环境旧枪生成样例改用受管正式枪，并加入 `/tacztest scope_kit` 生成不会删除的旧物品样例供验收。`compileJava adapterTest compileStandaloneCore verifyPlatformExtensionBoundary --offline` 通过；Minecraft 内的创造栏、配方/JEI、命令和旧物品行为待所有者集中验收。NewMod 主仓固定制品与锁见对应提交，不以本记录代替实机结果。

### 2026-09-18 批量作者关系前检：避免配置错误时先写半批资源

`tools/native_guns/batch.py` 在生成前只读检查整批作者关系/安装点，新增 `--preflight-only` 快速入口；`produce.py` 复用 M4 的关系校验，原 M4 校验改为可接收不同根定义，默认行为保持。拒绝重复定义、未知/重复候选、不兼容默认件、默认装配循环、缺失关键/供弹路径；单枪先检查关系与安装点，再写共享资源。没有改变枪的关系、运行代码或 UI。

新增 9 项测试，其中实际复现并修复了坏安装点仍先写共享资源、后枪配置错误仍先生成前枪的问题。通用工具完整 28 项、M4 完整 21 项通过；14 枪前检及目录一致性通过。SCAR-L/M870 代表两种供弹形式重新生成并校验通过（26.47/6.82 秒），运行资源与提交前完全一致；两份共享枪托 JSON 格式差异核对后恢复。只修改工具/文档，未重复构建或换宿主测试包、未启动游戏或推送。

前检覆盖声明关系与安装点，不是整批事务；后续模型解析或磁盘写入异常仍可能留下已完成枪的输出，不承诺自动回滚。本步不改变上一批实机及历史全仓门禁限制。
