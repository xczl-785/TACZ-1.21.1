## 完整依赖边界

inventory.json 列出54枪的索引→数据→展示→口径→脚本，172配方的结果及隔离判定、JSON/Lua中显式ID引用、默认包全部3322文件及哈希。为覆盖模型、动画、Lua字节码、间接资源命名等不能仅凭字符串可靠删除的引用，采用保守完整闭包：**所有原资产文件都保留，只封闭内容入口**。这不是磁盘瘦身。

必须保留的依赖：

- 45枪的数据、展示、模型、贴图、音效、动画、共用Lua与附件定义。
- 24份 ammo 索引及对应展示/弹壳/弹道资源。ShellRender、EntityBulletRenderer、AmmoParticleSpawner、BulletHoleParticle 均按枪上的原 ammo_id 查这些定义；这些ID是当前渲染与口径桥的契约，不等于保留原弹药物品玩法。
