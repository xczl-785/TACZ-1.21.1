## 为什么15定义对应24模型

6枪口有独立attachment模型（215方块）；9个扩容等级没有独立装枪geo，实际显示取自枪体mag_extended_N子树。展开原生兼容标签后覆盖Glock17/UMP45/Uzi的轻型、AWM/M700的狙击、M870的霰弹等级，各3件，共18变体（231方块）。骨骼祖先保留坐标和动作归属，仅去掉其他零件几何；弹头及其他原枪部件没有混入独立变体。M870记录为弹仓管延长外形，未虚构成可拆卸盒式弹匣。

运行资源在tacz_assembly命名空间中隔离打包，由未来每枪profile显式引用。没有注册额外物品、改原枪display或把这些配件强制加入M4；当前只完成资产准备，其他14把枪的实体组装接入仍待后续批次。
