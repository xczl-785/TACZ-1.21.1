# 原生 M4A1 实体组装交付

2026-09-16。第三项实施入口；授权见[完整实施合同](../整合与组装路线.md)。工程验证与制品关系记录在本目录证据文件；主控复核、用户实机接受分别记录，不能由构建通过推定。

## 新增内容

- 独立枪 ID：`tacz_assembly:m4a1`。原 `tacz:m4a1` 与 `newmod_adar:adar`、`newmod_radian:radian`、`newmod_m4a1:m4a1` 保留。
- 默认 15 个实体节点：下机匣根、上机匣、连接环、枪管、导气总成、前后瞄具、枪机、拉机柄、标准护木、手枪握把、缓冲管、CTR 枪托、30 发空弹匣、默认枪口；空膛。
- 共 15 个新注册物品身份（整枪根及 14 种零件，包含互斥的两种护木）；复用 52 种原生附件身份，未复制注册 `tacz:attachment`，未删除全局 85 附件。
- FMJ/HP/I 三种旧效果附件在本枪目录中没有安装位置。导轨护木才接受前握把/激光。M9 装在真实默认枪口下；换成其他枪口返还完整默认枪口/M9 子树。拆卸不免费再生默认件。

## 单一状态与运行链

装配保存在 foundation `AssemblyState` 的真实 ItemStack 树。安装先经过现有组装引擎，再由 tactical 完成扣除与返还；空间不足或旧报价失效时不写入。Z 与组装工作台共享 `AssemblyProposalSessions` 和 `AssemblyGunExchange`，会话单次使用、1200 tick 到期，原有持枪租约及库存版本复核保留。

原生附件查询读取树里的实体，倍率与激光颜色也写回该实体。不保存另一份 `GunAttachment` 数据。安装/卸载入口要求组装交易，不能通过原生存储接口偷偷创建副本。成功提交后刷新两侧属性；拒绝的提交不刷新新枪属性。

核心机构缺失禁射；无弹匣不能装填，移除弹匣退还现有弹药数、保留膛内一发。缺少两件机瞄且没有瞄具时不能进入瞄准。原 86 弹、口径固定退弹临时接口和既有精确弹种桥接不变，没有新增退弹键。

## 模型、动作与 LOD

制作入口：`tools/native_m4a1/generate.py`；原生文件只作输入。原 140 个骨骼及父子关系保留，几何放入独立叶节点按实体显示；不把安装树当动画骨骼树。17 个本枪动画、继承轨道、状态机、音效、装填时机、镜内渲染、倍率、挂点、枪口火焰与抛壳沿用原生资源。

高模资产共 938 个方块，低模 135 个方块；这是包含互斥变体的资产数量，不含独立附件，也不是每帧绘制量。68 个原生休眠 OEM 枪托方块不进入派生高模；CTR 使用实际附件渲染。低模保留并重绑 47 个原低模方块，原 28 个混合区域由分实体表面替换，补足两护木、四弹匣和折叠准星。每骨骼选取不超过两块较大原生表面作派生低模；细小结构简化，必须由所有者检查远景观感。

重绑中立矩阵最大误差约 `8.9e-16`。低模图集明确拼接原高/低模纹理；UV 使用对应区域。高低模调用同一实体遮罩，普通与加速渲染共享稳定叶节点，不改每帧 cube 列表，不建立装配组合缓存。原生低模加载器新增可选类型构造入口，只给新样本注册；旧枪继续使用原低模方式。

工作台使用原生中立几何与安装挂点的灰模预览；独立零件缩略图由几何生成。持枪仍使用原生贴图，不使用旧导入枪 meshScale 或二次姿态。各零件没有独立称重数据，本项没有虚构零件质量；枪械执行属性继续取原生枪数据和实际附件修饰。

## 所有者验收

1. 在 NewMod 使用既有 `启动开发客户端.command`。本任务不启动游戏、不修改日常世界。
2. 使用有权限的 `/devitems` 打开开发领取界面，按来源 `native_m4a1` 或名称 `M4A1 · 原生实体组装` 查找。默认枪与新零件由制作目录供给，原生附件也可在 `tacz` 来源领取。不要用普通 `/give` 裸 ItemStack 代替组装预设。
3. 持枪按 Z：原生附件改装；左上“打开组装工作台”进入完整实体拆装。两个界面应显示同一安装结果。标准与导轨护木是不同物品，不能装握把后自动变形。
4. 检查拆装、替换父件、装满背包时拒绝返还、连续提交、换手后旧操作；确认没有复制、丢件或免费补件。检查 M9 随默认枪口返还、拆下倍率/激光后再装仍保留状态。
5. 检查缺核心机构禁射、无弹匣不能装填但膛内一发可打、无瞄具不能瞄准；检查 30/40/50/60 发容量及真实弹种。
6. 检查持枪、机瞄、瞄具镜内与倍率、空仓/战术换弹、检视、挂机、射击、抛壳。切换两把不同装配的枪，检查近远、第三人称、地面、展示框及保存重进；检查低模细节是否可接受。
7. 回归原 `tacz:m4a1` 的 Z 改装、三把导入枪、弹药及防护链。

自动证据没有执行动画播放或测 FPS，也没有代替库存联机与实际渲染验收。第四/五项不在本次范围。
