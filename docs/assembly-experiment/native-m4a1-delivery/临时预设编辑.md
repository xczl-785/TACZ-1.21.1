# 临时预设编辑

2026-09-16，用户授权在完成RK-1装枪方向修正后追加。本轮目标完整形态是可自由试装、可撤销与恢复、关闭即丢弃的临时工作台，不是保存预设系统的临时实现。

## 状态归属

`AssemblySession` 的原有限库存构造器保持。新增预设工厂复制整个进入树并分配新UUID；每个目录定义只有一个稳定选择标识，实际安装或预览时才创建新的配件实例。预设提交只改内存树与撤销历史，不消费目录，也不积累拆下件。

界面复用 `WorkbenchScreen`，用可选模式动作进入/返回，不增加另一套组装器。临时模式显示完整目录提示与关闭丢弃提示；原生属性说明保持，不把原生枪械换算成虚构塔科夫数值。完整性与冲突仍由原引擎决定。

真实工作台仍由 `AssemblyGunClient.Host` 和服务器 `AssemblyGunWorkbench` 授权交换。临时工作台持有独立 `AssemblySession`，没有网络提交入口。进入临时时清除真实报价token及真实Host引用；返回真实模式重新申请服务器快照。异步请求通过 `AssemblyWorkbenchLifecycle` 同时核对请求ID与所归属的界面，关闭、换界面或切换模式后，旧响应无法跨入新状态。临时模式不因手持物变化发起刷新。
