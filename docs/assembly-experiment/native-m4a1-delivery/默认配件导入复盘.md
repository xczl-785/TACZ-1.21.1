## 问题与经验

- 原生方块被旧导出合并成三角网格，形状仍是模型，但不利于逐块编辑。此次直接提取原生方块作为编辑源，三角网格留给生成阶段。
- 旧导出把 PNG 像素尺寸当成 UV 单位。M4 实为 256 UV 对应 512 PNG，CTR 为 64 对应 128；此次按模型 UV 单位归一化。其余候选仍属后续批次。
- Blockbench 保存会将坐标保留到约五位小数。最初独立配件使用高精度中心，保存往返会产生细小差异；改用五位小数中心后，15 件坐标/UV 往返检查通过。
- CTR 是其他枪共用的原生配件。此次只在组装 M4 内接管其显示，并在切换备用枪托时保留原生渲染；未改共享配件身份或其他枪。
- 早期总览铺得太散、视角不便查看。后续区分可编辑分件源、整枪查看副本和拆解查看副本，明确后两者不回写。

保留：一套编辑来源生成多处显示；逐件记录来源/安装位置；工程验证与用户实机验收分开。改进：把朝向、透明度及纹理采样作为图标生产合同。停止：手工分别维护图标/工作台/持枪三套几何，或从三角网格反推已有原生方块。
