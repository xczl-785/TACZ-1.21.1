# 配件枪正式身份切换

日期：2026-09-19

## 结果

- 十五把配件枪是唯一正式枪械，统一使用 `tacz_fork_tarkov:<枪名>`。
- `GunAdoption` 不再接纳原版 `tacz:<枪名>`；原版枪索引同时由资源过滤策略阻止从旧包或外部包回流。
- 正式枪及其本地物理零件资源由 `tacz_fork_tarkov` 命名空间拥有；仍实际使用的 TaCZ 动画、声音、骨骼和通用附件继续作为引擎依赖保留。
- ADAR、单独导入 M4A1、Radian 三套运行资源、34 个专属零件、作者输入和专属材质已删除。
- 五个未被正式枪使用的 `ammo_mod_fmj/he/hp/i/slug` 附件定义已删除，并阻止外部包重新引入。

## `native_m4a1` 的含义

它原本同时承担“离线作者源目录”和“游戏开发目录分类”两种职责。本次拆为：

- `authoringSource`：逐枪唯一，例如 `native_m4a1`，只用于生产工具找到可编辑来源。
- `developmentCategory`：十五枪统一为 `tacz_fork_tarkov`，用于游戏内开发物品获取分类。

这不会合并十五把枪的来源或身份；每把枪仍有独立 ID、装配目录和重建证据。

## 兼容边界

本次明确不提供旧世界、旧物品 ID 或三套废弃导入内容的迁移。验收应使用新世界；自动检查不替代所有者实机验收。
