# 弹药链路与清理：当前结果

2026-09-15，`TACZ-1.21.1-experiments` / `experiment/standalone`。

## 目标与结果

**本 Mod 面向现有配套环境，不要求脱离适配器独立生存装填。** 先前把“独立装填”列为待做目标的判断已按所有者指示撤销。

当前目标是清除 TaCZ 原生子弹物品链，保留全部 86 种塔科夫弹药，用明确的临时接口承接原生退弹调用。现已移除 `tacz:ammo` 注册及其创建、渲染、JEI、配方生成入口；删除 5 个专属 Java 类和 87 个物品资源文件。此前两张无引用图片的删除是前一批，不重复计入本批。

原生口径标识和弹丸效果不是原生子弹物品：24 个口径/效果索引保留，其中 9 个供当前 15 把枪使用。枪模、动画、Lua、枪械配置、抛壳模型/贴图、弹丸显示/粒子/曳光、组装模块和改装接口未改。86 弹的旧 ID、注册实现、输入、生成文件与资源均保留。

## 临时退弹接口

入口：[TemporaryAmmoRefund.plan](../../src/main/java/com/tacz/guns/ammunition/TemporaryAmmoRefund.java)。

场景：例如一把 5.56×45 枪里有 20 发需要退出，默认退弹路径返还 **20 发塔科夫 M855**，不会生成 TaCZ 通用子弹。这里不判断原先装的是 M855 还是 M995，固定转换是所有者明确选择的临时行为。

- `TemporaryAmmoRefundPolicy` 只保存固定映射和分堆规则；`TemporaryAmmoRefund` 把它转成实际塔科夫物品。
- 普通实物退弹先生成完整返还清单，再清空枪内弹匣计数，交给原来的物品返还路径；背包放不下沿用其掉落行为。只在服务端执行，不退膛内弹。
- 未配置口径返回无方案，保留枪内弹数，不用别的口径凑数，也不回退到旧子弹。
- 背包直读、虚拟备弹、创造模式和燃料型枪维持原有分支。这些分支不走本次固定实物返还规则。
- **临时标识与替换条件**：类名、JavaDoc、调用处及映射表均明确 TEMPORARY。等本环境的枪内具体弹种与精确退还接好时，替换这一调用并删除固定映射。它不参与装填、伤害或永久写入枪的弹种身份。
- 现有 NewMod `ReloadMixin` 若接管某把枪，仍会取消 fork 方法并按自己的实际弹种退还，不会再执行一次固定返还。没有改 adapter、改装入口或让它退化成固定弹种。已检查 adapter main 源码不引用本次删除的原生物品类/API；这不等于重新完成联合运行验收。

## 清理范围

| 层次 | 当前处理 |
| --- | --- |
| 物品注册 | 移除 `ModItems.AMMO` / `tacz:ammo`；保留 86 个 `tarkov_content:ammo_<sourceId>` |
| 旧物品 Java | 删除 `AmmoItem`、`AmmoItemBuilder`、`AmmoItemDataAccessor`、`AmmoItemRenderer`、`AmmoTransform`；移除客户端初始化及 JEI 注册/子类型解释 |
| 退弹 | `AbstractGunItem.dropAllAmmo` 的物品返还段改用临时接口，修正旧分堆方式；现有改装调用签名不变 |
| 制作入口 | 两种配方解析入口和延迟结果初始化不再生成原生 ammo 结果；旧 `recipe/ammo` 加载过滤继续保留 |
| 创造栏/提示 | 弹药栏图标用 M855，列出全部 86 种真实物品；枪械提示直接显示口径名/数量，去掉旧子弹物品图标，不把固定 M855 冒充实际装入弹种 |
| 物品资源 | 删除 18 个原生子弹物品模型、68 张 UV/图标/伴随贴图和 1 个根物品模型，共 87 个文件 |
| display | 24 份配置只去掉物品 `model/texture/slot/transform`；shell/entity/particle/tracer_color 原值保留。客户端加载器不再先加载已删的子弹物品模型 |
| 口径索引 | 保留 24 个 ID、名称与 display 引用，移除旧物品 stack_size/sort 元数据及专属读取代码 |
| 必须保留 | 弹壳、飞行弹丸及其共享 `BedrockAmmoModel`、`IAmmo`/`IAmmoBox` 供弹接口、口径标识、所有 86 弹定义，以及现有枪械与配件机制 |

**旧存档边界**：`tacz:ammo` 不再注册，本轮没有把存档中的旧原生子弹自动迁移成塔科夫弹药。固定接口处理枪内待退计数，不扫描或转换旧物品栈。日常世界未打开或改写。
