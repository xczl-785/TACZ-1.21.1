## 公共机制与审核发现

- 供弹策略显式区分可拆弹匣与内置管式供弹；M870储弹管与延长节按实体树配置，原生逐发脚本不变。更换容器/容量组件原子退回储弹、保留膛弹。
- 视觉依赖支持“任一变体存在”和“多个实体同时存在”，避免AWP/M870膛弹因OR误用悬浮。独立前后机瞄必须成对；光学替代仍按原生槽位。
- 注册前检查补充供弹路径、机瞄数组层次、占位符、原生开火模式、门禁骨名存在性；库存身份直接对真实foundation分类核对，避免新枪错误标签。
- AA12原tag引用鸭嘴枪口但缺原生index；模型/贴图/data/名称原已存在，未列在历史删件计划。本轮仅新增缺失index（原包唯一新增项，不更改既有文件），并从原资源生成16cube独立编辑源与隔离补充库。

## 实机反馈：公共显示质量修正

所有者指出组装台枪身缺少第一人称的锐利质感、旋转缩放时细纹闪烁，主武器槽整枪图也因放大而发糊。本轮只改公共显示链，不修改15枪几何、原生动画、装配规则或光学内容：

- 工作台所有独立材质首次加载后生成完整mipmap，使用锐利放大与分级缩小采样；原线性模糊且无mipmap的组合已移除。
- 工作台背景改为低对比石墨渐变、轻网格和暗角，卡片布局、交互、相机和模型范围不变。
- 当前装配整枪图改为512×192横向缓存，按装配外观更新；64MB总预算和LRU淘汰防止随组合数量无限占用显存。
- 离线M4生成基准由256×256约11.4ms变为512×192约13.6ms；生成只发生在外观缓存未命中时，每帧仍只绘制纹理。工作台纹理mipmap只在材质GL对象首次出现时生成，实时拖动继续沿用原几何批次。

专项测试与完整`check assemble --offline`通过；静态证据不能代替所有者对实际清晰度、背景观感和拖动流畅度的验收。未启动Minecraft、未修改世界、未推送。
