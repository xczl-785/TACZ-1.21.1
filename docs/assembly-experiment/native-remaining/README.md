## 公共机制与审核发现

- 供弹策略显式区分可拆弹匣与内置管式供弹；M870储弹管与延长节按实体树配置，原生逐发脚本不变。更换容器/容量组件原子退回储弹、保留膛弹。
- 视觉依赖支持“任一变体存在”和“多个实体同时存在”，避免AWP/M870膛弹因OR误用悬浮。独立前后机瞄必须成对；光学替代仍按原生槽位。
- 注册前检查补充供弹路径、机瞄数组层次、占位符、原生开火模式、门禁骨名存在性；库存身份直接对真实foundation分类核对，避免新枪错误标签。
- AA12原tag引用鸭嘴枪口但缺原生index；模型/贴图/data/名称原已存在，未列在历史删件计划。本轮仅新增缺失index（原包唯一新增项，不更改既有文件），并从原资源生成16cube独立编辑源与隔离补充库。
- P90原生sight_p90使用default_sight外壳骨而不是scope_body；只读外壳投影用显式配置兼容，不创建光学编辑源，不改变第一人称光学行为。
- 模型归属除了总量/坐标校验，还查看配件图标；M700初版同骨cube区间归属被视觉检查发现错误，已纠正并重新经Blockbench复验，主线程逐件图标复核通过。
